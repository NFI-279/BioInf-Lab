# Bioinformatics — Lab 1 (Python)

Independent Python implementations of the two exercises, using the exact sequences from the reference files.

## Exercise 1 — DNA nucleotide frequencies

`ex1.py` analyzes `ATGGCCAATGAGTGGAATCG` (20 bases). It prints the number and percentage of A, C, G, T, including the sequence length. Expected counts: A=6, C=3, G=7, T=4.

## Exercise 2 — Overlapping DNA combinations

`ex2.py` analyzes the same 20-base sequence followed by 20 C nucleotides (40 bases total). It counts all overlapping dinucleotides (2-mers) and trinucleotides (3-mers), and prints the frequencies alphabetically. Expected total windows: 39 for 2-mers, 38 for 3-mers. Repeated combinations are counted with overlaps.

## Run on Windows

Extract this ZIP, open its folder in VS Code, then run:

```powershell
py ex1.py
py ex2.py
```

No additional Python packages are required.

Optional automated verification:

```powershell
py -m unittest discover -v
```

Both programs print their results to the terminal. The `outputs/` folder also contains example terminal results generated by running each program.
